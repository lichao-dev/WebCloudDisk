## 第六遍：专门理解异步代码

重新回头找这些调用：

```
response->add_task(task);
response->Compute(...);
```

需要区分：

- `add_task()`：把数据库任务加入当前 HTTP 请求的异步任务序列。
- `Compute()`：把 PBKDF2、文件哈希等耗费 CPU 的工作放到计算线程。
- 回调函数：数据库任务完成后继续执行后续逻辑。

这部分是项目里最难理解的地方，不建议第一遍就深挖。
